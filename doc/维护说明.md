# 知识库维护说明

> 本知识库为**个人公共知识库**：内容面向任何人可读，因此维护约定的核心只有一条 ——
> 只收录「自己原创、可公开、无版权与保密争议」的内容。本页说明收录边界、素材版权、仓库结构与发布流程。

## 1. 收录边界

1. 仅收录通用技术内容：工具用法、排障记录、学习笔记、公开协议与开源组件的接入方法；
2. 任何雇主、客户或第三方的私有信息一律不进本库：内部接口地址、内网 IP、网络拓扑、账号、客户数据、内部文档正文与截图；
3. 敏感值（token / 密码 / 密钥）一律脱敏为占位符；已在聊天、截图或历史提交中出现过的秘密值视为泄露，先轮换再发布；
4. **职务作品不收录**：源自雇主项目的代码片段、内部文档改写稿、业务规则描述均不放入；确需记录某类问题时，只写通用原理并用自行组织的语言与示例重述；
5. 不收录他人未公开的内容（私聊结论、付费课程笔记等），除非获得授权。

## 2. 素材与版权

1. 配图仅使用**自绘素材**（无水印 SVG / 自行截图并脱敏）；不使用带他人水印、付费授权或 AI 生成带标识的图片；
2. 描述第三方产品界面时，只文字描述字段与操作流程，或绘制**示意性线框图**；不复制其美术资源、图标与商标图形；
3. 正文为原创整理；引用他人观点、文字或代码片段时注明出处与链接，并遵守其许可证（如 MIT / Apache / CC）；
4. 本库内容以个人学习笔记性质发布；转载或引用请注明来源链接。

## 3. 仓库与目录结构

1. 本库是**独立 Git 仓库**（`main` 分支），物理上可嵌套在任意宿主工作区目录内；
2. 宿主仓库通过 `.gitignore` 忽略本目录，两库提交互不影响；⚠️ 切勿在宿主仓库对本目录执行 `git add`，嵌套仓库会被登记为 gitlink(160000)，内部文件将脱离宿主跟踪；
3. 目录约定：
   - 根目录：`README.md`（首页链接索引）、`index.html` / `_sidebar.md`（站点引导与侧栏）、`.nojekyll`（必须保留）、`vendor/`（本地化前端库）；
   - `doc/`：全部文档；`doc/notes/` 单篇笔记；`doc/images/` 自绘 SVG。

## 4. 发布流程

1. 本地编辑 `doc/` 下 Markdown（新增文档时同步在 `README.md` 与 `_sidebar.md` 登记）；
2. 在本目录内 `git add . && git commit && git push`；
3. GitHub Pages（源：`main` + `/ (root)`）自动重新部署，通常 1~3 分钟；队列延迟时到仓库 Actions / Deployments 查看构建状态；
4. 站点为 Docsify **运行时渲染**：左栏分组由 `_sidebar.md` 定义，点进文档后自动展开其标题树并可逐级折叠；右侧大纲由 `index.html` 内联插件生成；
5. `.nojekyll` 缺失会导致 Jekyll 吞掉下划线文件（`_sidebar.md` 404、侧栏消失），切勿删除。

## 5. 前端依赖维护

1. `vendor/docsify/` 为本地化库文件（docsify 4.13.1 + docsify-sidebar-collapse 插件 + 主题 CSS），站点零外部 CDN 依赖；
2. 升级方式：下载新版同名文件覆盖 → 提交推送；无需改动 `index.html`；
3. `index.html` 内的 `<style>` 块为阅读风格覆盖层（白底侧栏、窄栏正文、语雀式表格/代码样式），整体删除即回退 docsify 默认主题。
